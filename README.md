# Resilience Scoring Program

This project builds CRSS, a quantitative method for quantifying the resilience degradation targeted to OT systems.
The algorithm is generic, working for both SW systems and CPS systems.

The project builds dependency graphs for two CVE scenarios, calculates civilian and military resilience scores, and writes the results to a text report: report.txt.

## What the program runs

The current runner evaluates four combinations:

- CVE-2014-0160, unprotected
- CVE-2014-0160, protected
- CVE-2017-0144, unprotected
- CVE-2017-0144, protected

All these combinations are described in the paper

For each combination, the report includes overall resilience and resilience by system layer. 

Values are normalized between 0 and 1. The program also assigns each layer a resilience level (L1 to L4) using the intervals printed at the top of the report.

## Requirements
-- the program is not resource intensive and can be safely ran on any laptop/desktop 

- Windows with PowerShell
- Python 3.10 or newer
- The Graphviz application, including its `dot` command
- Python packages: `numpy`, `graphviz`, `pydot`, and `matplotlib`

--- instructions for graphviz - used to generate the dependency graphs -
This library is used by CRSS to create a digraph object and represent it visually. Each digraph represents a resilience degadation path from the entry point to the cut-point (the point beyond which the degradation does not propagate amymore).

The Python package named `graphviz` does not install the Graphviz application itself. 
Install the application separately. With Windows Package Manager, you can use:

# in powershell
winget install --id Graphviz.Graphviz -e

Alternatively, install it from [graphviz.org/download](https://graphviz.org/download/). 
After installation, open a new PowerShell window and check that Graphviz is available:

# in powershell
dot -V

## How to set up the Python environment

Open PowerShell in the project folder (the folder containing this README) and create a virtual environment:

# in powershell
py -3 -m venv .venv

Install the Python packages into that environment:

# in powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install numpy graphviz pydot

The virtual environment keeps the project's packages separate from other Python installations on your computer.

## Run the program

The main script is crss.py. 
From the project folder, run:

# in powershell
.\.venv\Scripts\python.exe .\resilience_estimator\crss.py

The program creates the `output` folder if needed, generates graph files there, and writes the results to:

output/resilience_report.txt

The files obtained by traversing the propagation paths in both directions are placed in the poutput folder both as digraph files, dot files (generated by graphviz) and as images (svg and png)

Each run replaces the previous resilience report with a newly generated one. Graph files in `output` are generated or updated as the scenarios are evaluated.

## Read the report

At the beginning of the report:

- Resilience Classification Intervals** shows the numeric boundaries for levels L1-L4.

- CR is the AHP consistency ratio for the expert reference values used to build those intervals. A lower value indicates more consistent pairwise judgments; this project checks that the default ratio is below 0.1.

Each scenario section then lists civilian and military resilience, both overall and for the HW, FW, NETW, and APPL layers. The level in parentheses is the classification of that layer's score according to the intervals above.

## Change the scenarios

The four scenarios are listed in `resilience_estimator/crss.py` in `cve_scenarios`. Each entry contains the CVSS score and CVE name, a label used in the report, and a protection value (`0` for unprotected or `1` for protected). The graph-building code must also support a CVE before it can be used by the runner.

The model parameters `R0`, `mop`, `MT`, and `MO` are supplied in the call to `resilienceCalculatorForCVE` in the same file. Change them only if you intend to change the model assumptions.

## Run the MO/MT sweep

To evaluate the unprotected CVE-2014-0160 scenario for all 100 combinations of `MO` and `MT` from 0.1 to 1.0, run:

```powershell
.\.venv\Scripts\python.exe .\resilience_estimator\crss2.py
```

The script saves a 3D surface graph to `output/CVE-2014-0160_unprotected_military_resilience_surface.png` and the 100 measured values to `output/CVE-2014-0160_unprotected_military_resilience.csv`. It stores any dependency graph files generated during the run under `output/crss2_graphs` to keep them separate from the other output files.
